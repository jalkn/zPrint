## Fundamental principle

ONE GENERATOR — COMPLETE FRAMEWORK — MODULAR APPLICATION — CONTROLLED GENERATION.

The generator is one physical PowerShell script.

The application generated by that script consists of independent source files organized into modules.

All framework source templates will eventually be embedded in the structured registry inside `zprint.ps1`.

Do not implement an enormous application as one HTML, JavaScript or Python file.

Do not create external template files that become required dependencies for reconstructing the framework.

## 9.7 Error handling

Use this exit-code contract:

| Code | Meaning |
|---|---|
| 0 | Successful execution |
| 1 | Validation or build failure |
| 2 | Invalid command or arguments |
| 3 | Missing or invalid configuration |
| 4 | Environment or dependency failure |
| 5 | File conflict |

Do not swallow exceptions.

Do not convert failed operations into success.
